# Android APK — технический прототип

Цель: проверить сборку простого проекта Godot 4.5.1 через GitHub Actions.

1. Открыть вкладку **Actions** репозитория.
2. Выбрать **Android debug APK** и запустить **Run workflow**, если он не запустился после push.
3. Дождаться успешного завершения job **build**.
4. Скачать artifact **ai-game-studio-debug-apk** из страницы запуска.
5. Распаковать ZIP и установить APK на Android-устройство, разрешив установку из этого источника.
6. Убедиться, что открывается экран AI GAME STUDIO и кнопка TEST BUTTON меняет надпись.

Важно: до успешного workflow и установки APK проект нельзя считать проверенным. Debug APK не предназначен для публикации в RuStore. Для релиза потребуется отдельная подпись, конфигурация приложения, проверка рекламы и политики магазина.

Если сборка падает, сначала прочитать логи Actions; не утверждать, что APK создан.

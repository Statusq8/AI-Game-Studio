# Журнал решений

Статусы: **утверждено**, **открыто**. В этом файле приведено содержание известных решений, а не дословная стенограмма чатов.

## Бизнес-стратегия: вопросы №1–10 (утверждено)
1. Цель: от 300 000 ₽ чистой прибыли в месяц.
2. Начальный бюджет: 10 000–50 000 ₽.
3. Готовность активно работать на старте, затем минимизировать участие.
4. Приоритет прибыльности, без жёсткой привязки к отрасли.
5. ИИ делает максимум работы, пользователь проверяет и принимает решения.
6. Рынки России и зарубежья.
7. Есть компьютер; программировать самостоятельно не умеет, готов использовать ИИ-код.
8. Умеренный риск; предпочтение нескольким небольшим экспериментам.
9. Допустимый горизонт до первых доходов: 3–6 месяцев.
10. Готовность платить за рекламу с контролем расходов владельцем.

## Игровая студия
11. **B, утверждено:** выпускать много небольших игр, тестировать доходность, развивать победителей.
12. **D, утверждено:** разные жанры, выбирать по потенциалу.
13. **B, утверждено:** качественная премиальная 2D-графика и анимации.
14. **A, утверждено:** максимальная самостоятельность ИИ в разработке; важные решения и тестирование — за владельцем.
15. **B, утверждено:** единый переиспользуемый игровой фундамент, отдельное Android-приложение для каждой игры.
16. **B, утверждено 2026-11-13:** Godot + GDScript — основной движок студии. Перед полноценной разработкой проверить Android-сборку и совместимость рекламной интеграции.
17. **A, утверждено 2026-11-13:** сначала минимальный проект Godot, автоматическая Android-сборка APK через GitHub Actions и проверка запуска на телефоне. Реализация и проверка — отдельные статусы. **Выполнено 2026-11-13** (APK запущен на телефоне).
18. **C, утверждено 2026-11-13:** до фундамента и выбора игры проверить рекламу с вознаграждением в Godot на тестовом APK. Для технической проверки используется Яндекс Реклама (Yandex Mobile Ads SDK 8.x) с демо-блоком `demo-rewarded-yandex`; выбор рекламной сети для релиза — отдельное решение. **Выполнено 2026-11-13:** награда за просмотр работает на телефоне.

# «Охотник за Вратами» — стиль и промпты для генерации графики

Решение №22 A: графику генерирует владелец по этим промптам (например, Nano Banana), Claude доводит до игры.
Все персонажи и образы оригинальные. Не добавлять в промпты имена чужих тайтлов, персонажей или художников.

## Единый стиль (добавлять в каждый промпт)
`Korean webtoon style digital painting, clean bold lineart, cel shading with soft gradients, dramatic rim light, saturated neon accents, high detail, game asset`

## Правила для персонажей и монстров
- Один персонаж во весь рост, 3/4 вид, смотрит вправо, боевая стойка.
- Фон **сплошной белый**, без теней на полу, без текста и рамок.
- Формат 1:1.
- Сначала утверждаем эталон персонажа, потом делаем позы/вариации с этим эталоном как референсом.

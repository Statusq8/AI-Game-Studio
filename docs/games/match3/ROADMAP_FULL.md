# «Три в ряд» — полный набор механик жанра (по модели Royal Match)

Берём устройство игры (механики жанра), всё содержимое своё: панда и зоопарк, свои названия, графика, уровни, тексты.
Чужие названия, персонажи, графика, логотипы и уровни не копируются — за клоны магазины удаляют игру, и это нарушение прав.

| Механика | Статус |
|---|---|
| Поле, свапы, каскады, перемешивание, подсказка | ✅ 0.1 |
| Ракета, бомба, радужный шар, пропеллер + все комбо | ✅ 0.2 |
| Препятствия: ящики, вазы, цепи, трава, предметы вниз | ✅ 0.2 |
| 5 жизней с таймером, жизнь за рекламу | ✅ 0.2 |
| Финал уровня: оставшиеся ходы → ракеты | ✅ 0.1 |
| Бустеры на уровне (молот, ряд, столбец, микс) | ✅ 0.4 |
| Бустеры до уровня (ракета, бомба, шар) + окно перед уровнем | ✅ 0.4 |
| +5 ходов за монеты/рекламу при проигрыше | ✅ 0.1 |
| Звезда за уровень → ремонт зон зоопарка (задания за звёзды, зоны открываются) | ⏳ 0.5 |

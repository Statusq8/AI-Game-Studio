# AI Game Studio

Приватный рабочий репозиторий мобильной ИИ-студии.

## Цель
Разрабатывать и тестировать небольшие Android-игры разных жанров с качественной 2D-графикой и добровольной рекламой. Целевой ориентир владельца — 300 000 ₽/мес чистой прибыли, без гарантии достижения.

## Документы
- docs/STUDIO_GDD.md — концепция и архитектура.
- docs/DECISIONS.md — журнал утверждённых решений и открытых вопросов.
- docs/ROADMAP.md — план реализации.
- docs/DEVELOPMENT_STATUS.md — фактический статус.
- docs/NEXT.md — точка продолжения в новом чате.

Важное правило: не утверждать, что код, сборка или публикация выполнены, без проверки. Существенные изменения, расходы и публикации согласовывать. Не трогать другие репозитории.
